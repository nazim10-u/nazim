# ربط مِداد مع VS Code

تضيف هذه الإضافة نقطة تسليم آمنة من نموذج مِداد إلى وضع Agent في Copilot Chat. لا تكتب الإضافة ملفات المشروع مباشرة: يراجع Copilot التغييرات في VS Code، ويظل قبولها بيدك.

## المتطلبات

- Visual Studio Code 1.85 أو أحدث.
- إضافة GitHub Copilot Chat مفعّلة ومسجّل الدخول إليها.
- فتح مجلد المشروع الذي تريد العمل عليه في VS Code.

## تشغيل الإضافة محليًا

1. افتح مجلد `vscode-extension` في VS Code.
2. اضغط `F5` لفتح نافذة **Extension Development Host** وتشغيل الإضافة تجريبيًا.
3. في نافذة **Extension Development Host**، افتح مجلد المشروع الذي تريد أن يعمل عليه Copilot.
4. افتح `index.html` في المتصفح، وانتقل إلى قسم **مساعد الأكواد**.
5. اكتب وصف ما تريد بناءه واضغط **تابع إلى VS Code**.
6. وافق على فتح VS Code، ثم راجع نافذة التأكيد قبل إرسال الوصف إلى Copilot Chat.
7. راجع التغييرات المقترحة في مساحة العمل واقبل ما تريده فقط.

إذا كان الملف مفتوحًا مباشرةً من القرص، فقد يعرض المتصفح تحذيرًا قبل فتح VS Code. يمكن أيضًا تقديم الصفحة من خادم تطوير محلي. لا ترسل أسرارًا أو مفاتيح وصول ضمن وصف المشروع.

## حدود النموذج الأولي

- يتطلب تشغيل الإضافة في نافذة VS Code؛ الصفحة وحدها لا تملك صلاحية الوصول إلى ملفات الجهاز.
- يستخدم توليد الكود خدمة Copilot المثبّتة في VS Code؛ لا يتضمن المشروع مفتاح API أو خادمًا خلفيًا.
- تعرض الإضافة تأكيدًا قبل إرسال الوصف، ولا تنفذ عمليات كتابة للملفات بذاتها.
